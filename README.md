# KADAYA — THE LAST SHADOW

The old Godot prototype has been replaced with a Unity 6 / URP 3D Android project.

## Game direction
- Landscape 16:9
- 3D dark-fantasy ninja world
- KADAYA as the main character
- Black SHADOW enemies
- Katana combat and takedowns
- Progressive Shadow Dash / Vortex direction
- Mobile-oriented URP rendering
- Android package: com.kyzerhadoc.kadaya

Open the project with Unity 6 and open Assets/Scenes/Kadaya.unity.

For Android builds, install Unity Android Build Support plus the Android SDK/NDK and OpenJDK through Unity Hub.
