# KADAYA

Kadaya is an original 2D mobile ninja action-platformer.

Current vertical slice:
- 16-year-old protagonist
- Cinematic opening sequence
- Title screen
- Side-scrolling combat prototype
- Jump + sword attack
- Progressive abilities
- Shadow Dash
- Signature energy ability: Vortex Sphere
- Enemy HP, damage, particles and progression
- Mobile-friendly visual controls
- Godot 4 / Android-ready project

Build:
Open this project in Godot 4.x and run Main.tscn.

The GitHub Actions workflow builds an Android debug APK automatically.

Roadmap:
1. Production-quality original art
2. Animated sprite sheets and VFX
3. Chapters, save system and upgrade tree
4. Bosses and story cinematics
5. Touch controls and accessibility
6. Audio, music and haptics
